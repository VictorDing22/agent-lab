# 单一来源理由撰写技能

撰写单一来源采购申请理由时，遵循以下步骤：

1. 先确认采购金额。如需查证专家论证/审批门槛，调用 search_policy 检索《单一来源采购管理办法》。
2. 申请理由必须包含四要素：
   - 采购标的（买什么）
   - 唯一性论证（为什么只能从这家买）
   - 价格合理性说明（价格依据是什么）
   - 不可替代性依据（技术/专利/配套等）
3. 避免使用被明确禁止的理由：
   - "供应商报价较低"
   - "关系稳定/合作愉快"
   - "采购人未提前规划导致时间紧张"
   - 可通过公开竞争获得的
4. 输出结构化的申请理由草稿，末尾注明引用了哪条制度（如"依据《单一来源采购管理办法》第X条"）。
5. 提醒：最终需人工确认，不得由 AI 直接提交。
