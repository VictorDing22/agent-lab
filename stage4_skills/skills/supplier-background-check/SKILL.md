# 供应商背调要点技能

评估供应商是否满足准入标准时，核查以下要点：

1. 基础字段是否齐全：法定代表人、统一社会信用代码、注册资金、成立年限、注册/经营地址、员工数量。
2. 资质是否齐全且在有效期内（关注 qualification_expire 是否临近或已过期）。
3. 背调材料是否完整（background_check 字段；"不完整"通常不满足入库）。
4. 风险核查：
   - risk_status 是否为"高风险"
   - 是否命中涉诉风险客户名单
   - 是否失信被执行人、经营异常
5. 准入门槛（参考《供应商准入管理办法》，可用 search_policy 核对）：
   - 注册资金不低于 100 万元
   - 成立满 2 年（关键设备满 3 年）
   - 近 3 年无重大违法违规
6. 输出：是否满足准入 + 缺失项清单 + 风险提示。高风险原则上不予准入，确需合作须专项论证。
