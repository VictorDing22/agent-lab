# agent-lab · 迷你采购智能体练手营

8 个递进关卡，在本地从命令行采购助手一路造到「查供应商、答制度、审风险、写单一来源理由」的采购智能体原型。
它是**西高院采购智能化项目的微缩版**——每一关对标真项目里的一个技术点。

**完全新手先读 [新手基础扫盲.md](./新手基础扫盲.md)**（Ollama 是什么、大模型/API/token/RAG 等基础概念大白话讲清）。

然后读 [学习指南.md](./学习指南.md)（真项目 vs 练手版对照 + 概念全景 + 环境准备），
[运行说明与验证结果.md](./运行说明与验证结果.md)（每关运行命令，已验证），
[采购数据/README.md](./采购数据/README.md)（数据底座），最后进入 `stage1_chat/README.md` 做第 1 关。

## 快速开始

```bash
brew install uv ollama
brew services start ollama
ollama pull qwen3:8b
ollama pull bge-m3

cd agent-lab
uv sync
uv run python stage1_chat/chat.py
```

## 关卡地图

| 关卡 | 主题 | 造出的零件 | 对标西高院方案 |
|---|---|---|---|
| 1 | 采购助手雏形 | LLM 对话 / 流式 / 上下文 | 采购智能助手 |
| 2 ⭐ | Agent 循环 + 查供应商库 | tool calling / ReAct | 工具集 + 供应商信息库 |
| 3 ⭐ | Harness + 模型网关 | 工具注册 / 护栏 / 网关 | MaaS/模型网关 |
| 4 ⭐ | 提示词/技能管理 | Skills / 渐进式披露 | 提示词管理 |
| 5 | 会话记忆与上下文 | 压缩 / 长期记忆 | Agent 会话态 |
| 6 ⭐ | 制度知识库 RAG | 切分/向量/混合检索/ReRank/出处 | 知识库 + RAG 可追溯 |
| 7 | MCP + 征信风控 | MCP server+client / 外部数据 | 工具集 MCP + 风险插件 |
| 8 | 三大采购场景毕业项目 | 工作流 / 权限 / 评测 | 采购智能场景 + 验收指标 |
