# 采购数据（迷你采购智能体的数据底座）

这是整个练手营的模拟数据，对标西高院项目里的"供应商信息库 + 制度知识库 + 外部征信数据"。
全部是**编造的示例数据**，仅供本地练习，与真实企业无关。

```
采购数据/
├── 供应商.json            ← 供应商主数据（第2关起用）：基本信息/资质/历史项目/风险状态
│                             注意 S001 与 S006 是同一家企业的两种写法，用于练"去重/名称归一"
├── 制度/                  ← 制度知识库语料（第6关 RAG 用），每篇带 frontmatter 元数据
│   ├── 单一来源采购管理办法.md
│   ├── 供应商准入管理办法.md
│   └── 采购管理办法.md
└── 外部数据/              ← 模拟外部接口（第7关 风控用）
    ├── 征信.json          ← 按统一社会信用代码索引的工商/司法/经营/舆情数据
    └── 涉诉风险客户名单.txt ← 中国西电涉诉风险名单（命中即高风险）
```

## 对标真项目

| 这里的示例 | 真项目里的对应 |
|---|---|
| 供应商.json | 供应商信息库（基本/背调/采购/风险信息） |
| 制度/*.md | 采购综合知识库（Word/PDF/扫描件解析后入库） |
| 外部数据/征信.json | 天眼查/企查查类企业征信 API |
| 涉诉风险客户名单.txt | 中国西电涉诉风险客户名单 |

真项目数据量更大、格式更脏（Word/PDF/扫描件/表格混排），且需要数据治理；
这里刻意做小做干净，让你先把链路跑通，再理解"数据不标准时 RAG 为什么难"。
