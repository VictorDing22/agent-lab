# 第 8 关 · 毕业项目：三大采购场景 + 工作流 + 权限 + 评测

**时长**：一个周末 ｜ **难度**：综合
**对标真项目**：采购智能场景 + 工作流编排 + 权限与安全 + 效果评测验收

## 本关目标

把前 7 关的零件拼成一个能用的迷你采购智能体，补上真项目最吃重的三块：
**工作流编排、权限过滤、评测验收**，并落地三个高价值采购场景。

## 动手任务

### 任务 1：工作流编排（一天）

真项目强调"复杂场景不能只做单轮问答，要用工作流串多步"。落地三个场景：

**场景 A：单一来源智能审核**
```
输入采购标的 + 金额
 → [查金额档位] 判断是否超 50万/200万门槛
 → [search_policy] 检索《单一来源采购管理办法》相关条款
 → [load_skill single-source-reason] 加载撰写技能
 → [call_model analyze] 生成申请理由草稿（四要素）
 → [合规检查] 是否命中"禁止理由"、是否需要专家论证
 → 输出草稿 + 合规提示 + 制度出处，等采购员确认（人工确认，不自动提交）
```

**场景 B：供应商智能推荐**（对标"推荐不能只做语义相似，要可解释评分"）
```
输入采购需求（品类 + 预算）
 → 召回该品类候选供应商
 → 对每家算综合评分：品类匹配、资质有效性、历史合作评价、价格水平、风险等级、背调完整度
 → 高风险直接剔除（依据《采购管理办法》第七条）
 → 输出排序 + 每家的加分/扣分项（可解释），供人工参考
```
注意：评分主要靠**结构化字段 + 规则**，不是纯 LLM。这正是真项目的正确做法。
也在这里处理 S001/S006 的**去重/名称归一**（同一信用代码视为一家）。

**场景 C：供应商风险审核**：直接复用第 7 关。

### 任务 2：权限过滤（半天）

给每个供应商加一个"所属单位"字段（自己在加载时按 ID 规则模拟分配），
结合第 5 关记住的采购员单位，实现：**检索/查询时先按单位过滤，再做召回**。
测试：设备部的采购员查不到只属于其他单位的供应商。
这就是方案里的"RAG 检索先做权限过滤再向量召回，避免越权数据误召回"。

### 任务 3：评测集（半天）

1. 建 `evals.jsonl`，20 个测试用例覆盖：制度问答、风险审核、推荐、单一来源、越权访问、语料外问题
```json
{"q": "单一来源超过多少钱要专家论证？", "expect_contains": ["50万", "第五条"]}
{"q": "远东电力风险等级？", "expect_contains": ["高风险", "失信"]}
{"q": "报销怎么走？", "expect_contains": ["没有", "无法"], "type": "negative"}
```
2. 写 `run_evals.py`：批量跑、自动判 expect_contains 命中 + 出处正确，输出得分表
3. **做一次真实调优**：改一个变量（切块大小 / 检索权重 / prompt），重跑评测，记录分数变化。
   体会方案说的"不能只凭演示样例验收，要用案例集测"。

## 验收标准（毕业条件）

- [ ] 三个场景都能跑通，回答带制度出处
- [ ] 单一来源场景保留"人工确认"，不自动提交
- [ ] 推荐场景给出可解释评分和扣分项，高风险被剔除，S001/S006 完成去重
- [ ] 越权供应商查不到
- [ ] 评测集 ≥ 70%，且有一轮"改动→重测"记录

## 毕业后：对照真项目的差距清单

你已经把西高院方案的每一层都写过微缩版。真项目多出来的是**工程量和规模**，不是新原理：

1. **规模**：几十条数据 → 几十万条；SQLite 全量算 → Milvus/Elasticsearch 向量库
2. **模型服务**：Ollama 单机 → 千问/DeepSeek 私有化部署 + 真正的 MaaS 网关（你已理解它要做什么）
3. **文档形态**：干净 md → Word/PDF/扫描件，需要 OCR + 多模态解析流水线
4. **检索质量**：简易加权 → Qwen3-Reranker/BGE-reranker 重排
5. **数据治理**：干净示例 → 供应商去重、名称归一、价格口径统一、制度版本管理（真项目最难的一块）
6. **外部接入**：假 JSON → 真企业征信 API（付费、限流、要缓存降级）
7. **权限**：模拟单位字段 → 继承采购系统的角色和单位权限体系
8. **交付**：命令行 → Web 界面 + 表单回填 + 培训 + 运维

把这份清单和你分析过的那份技术方案对照着看——
你会发现从"练手版"到"真项目"之间已经没有认知盲区，只剩工程量。这时候再去跟客户/团队谈方案，你是懂行的。
